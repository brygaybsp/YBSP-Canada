Version 33.1
Status: Completed / Targeted Maintenance Release (Bulletproof Mobile Hamburger Submenu Arrow Interaction & Navigation Architecture)
Baseline: Version 33 (100% Preserved)

Completed:
- Resolved Mobile Hamburger Submenu Arrow Interaction Bug (TASK 1):
  * Deep Root Cause Analysis:
    1. CSS Specificity Collision (The Primary Blocker): In Version 33, '#main-nav-menu .dropdown-menu' had 'display: none !important; opacity: 0 !important; visibility: hidden !important;'. Because it used an ID selector (#main-nav-menu), its specificity of (1, 1, 0) overrode the class-only selector '.nav-item.has-dropdown.is-expanded > .dropdown-menu' (0, 4, 0). Even when JavaScript added .is-expanded, the browser computed display: none !important, keeping the submenu completely hidden.
    2. Interactive Element Nesting & Ambiguity: The arrow was previously an unisolated inline child inside the parent <a> tag. On mobile touchscreens, tapping near or on the arrow was caught in touch event bubbling ambiguity.
    3. SVG Aspect-Ratio & Transform Distortion: The 10x6 viewBox on the inline SVG chevron clipped when rotated in mobile WebKit browsers.
  * Architectural Solution:
    1. Physical Element Separation: Created a dedicated '.nav-item-header' row separating '<a class="nav-link">' from '<button class="dropdown-toggle-btn" type="button">'. Tapping the link text touches strictly the anchor tag; tapping the arrow touches strictly the button control.
    2. High-Specificity CSS & Inline Safeguard: Configured '#main-nav-menu .nav-item.has-dropdown.is-expanded > .dropdown-menu' (specificity 1, 4, 0), and added direct inline 'style.setProperty("display", "block", "important")' as an absolute failsafe against any specificity conflict.
    3. Dedicated 48x44px Touch Target: Button is given an unmissable 48x44px touch target on the far right edge of the row with touch-action: manipulation.
    4. Square 12x12 SVG Chevron & Smooth Rotation: Designed a square 12x12 chevron (M4 2.5 L8.5 6 L4 9.5) that points right (›) at 0deg when collapsed, and smoothly rotates 90deg to point down (˅) when expanded.
    5. Dual Click & Touchstart Event Listeners: Handlers bound to 'click' and 'touchstart' with e.preventDefault() and e.stopPropagation() for instant touch reaction without 300ms mobile tap delay.
    6. Independent Submenu Mechanics: Opening one submenu does not force-close or break others.
    7. Desktop Integrity: On desktop (>= 992px), button rotates 90deg (downward) and sits inline with the link. Hover dropdowns and link clicks operate exactly as in Version 33.
- Verification & Stress Testing:
  * Executed comprehensive automated stress-testing across all 10 production templates ('about.html', 'careers.html', 'contact.html', 'donate.html', 'events.html', 'get-involved.html', 'index.html', 'news-single.html', 'news.html', 'programs.html').
  * 870/870 test assertions passed across mobile touch, click, collapse, expand, multi-menu combinations, parent link clicks, and desktop viewports.
  * Zero JavaScript errors, zero layout shifts, zero breaking changes to Version 33 baseline.

- Resolved Lightbox Gallery Image Rendering (events.html - Screenshot image_f23e2e.png):
  * Root Cause: In Version 32, the album photo objects had localSrc and fallbackSrc properties, but updateLightboxContent() attempted to assign imgEl.src = photo.src (which was undefined), causing the browser to attempt loading a non-existent URL and displaying a broken image icon.

If the local photo is not yet added, it seamlessly falls back to the online placeholder without ever exposing a broken image icon to the user.
